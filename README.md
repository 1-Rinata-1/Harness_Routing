## Harness Routing

Система автоматизации трассировки жгутовых межмодульных соединений в блоке электронного
средства с учётом критерия электромагнитной совместимости. В основе - модифицированный 
муравьиный алгоритм.

## Задача

При проектировании блока электронного средства нужно проложить кабельные жгуты между
модулями. Прокладка по кратчайшему пути приводит к тому, что несовместимые провода идут
длинными параллельными участками в одном жгуте, а это порождает перекрёстные помехи в проводниках
и ухудшает качество сигнала.

Трассировка выполняется по двум конфликтующим критериям одновременно:

- **F1** - минимизация суммарной длины проводников;
- **F2** - минимизация взаимных электромагнитных влияний, то есть суммарной длины
  параллельных участков несовместимых проводов в одном жгуте.

## Модель

Топология каналов прокладки представлена графом: вершины - узлы монтажной сетки, рёбра -
допустимые участки трассы; часть вершин занята точками коммутации модулей. Задача сводится
к поиску путей между заданными парами вершин с учётом критериев качества и ограничений.

## Алгоритм

Муравьиный алгоритм (Ant Colony Optimization) с модифицированным
вероятностно-пропорциональным правилом перехода: в него введён показатель совместимости
ребра, штрафующий прокладку несовместимых кабелей по общим участкам.

## Результаты

Проверка выполнена моделированием в CST Microwave Studio на блоке электронного средства
с модулями и кабельными линиями связи между ними:

Уровень помехи снижен в 90 раз при неизменной суммарной длине кабелей.
